## 📖 Problem Statement

Shagun is coordinating a placement drive at her college. The attendance sheet is represented as a long string **S**, where each character denotes a student from a particular department.

To start the interview process, the company requires that a group contains all the departments listed in another string **T**. The order of the departments does not matter, but every distinct department in **T** must be present in the selected group.

Help Shagun find the smallest continuous segment of the attendance sheet that contains all the characters of **T**. If no such segment exists, print **-1**.

---

## 📥 Input Format

* The first line contains a string **S**, representing the attendance sheet.
* The second line contains a string **T**, representing the required departments.

---

## 📤 Output Format

* Print the smallest continuous substring of **S** that contains all the characters of **T**.
* If no such substring exists, print **-1**.

---

## 💡 Example

### Input

```text
S = ADOBECODEBANC
T = ABC
```

### Output

```text
BANC
```
