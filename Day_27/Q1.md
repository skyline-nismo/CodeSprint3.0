## 📖 Problem Statement

Saanvi is analyzing signal strengths received from a satellite communication system.

The recorded signal strengths form a **bitonic sequence**, meaning:

* The values strictly increase up to a certain point.
* After that point, the values strictly decrease.

The strongest signal is called the **Peak Transmission**.

Help Saanvi determine the maximum signal strength received.

The expected time complexity is **O(log N)**.

---

## 📥 Input Format

* First line contains an integer **N**.
* Second line contains **N** space-separated integers representing signal strengths.

---

## 📤 Output Format

* Print a single integer representing the maximum signal strength.
* Print the **value** of the peak element, **not its index**.

---

## 💡 Example

### Input

```text
7
1 3 8 12 9 5 2
```

### Output

```text
12
```

---

## 📌 Constraints

| Constraint         | Value                                                |
| ------------------ | ---------------------------------------------------- |
| Number of elements | `3 ≤ N ≤ 10^5`                                       |
| Signal strength    | `1 ≤ Signal[i] ≤ 10^9`                               |
| Array property     | `The array is guaranteed to be bitonic`              |
| Peak element       | `There exists exactly one peak element`              |
| Peak position      | `The peak is neither the first nor the last element` |

---

## 💭 Hints

<details>
<summary><strong>Hint 1</strong></summary>

A linear scan can find the answer but does not satisfy the required complexity.

</details>

<details>
<summary><strong>Hint 2</strong></summary>

Compare `arr[mid]` with `arr[mid + 1]` to determine which side contains the peak.

</details>

<details>
<summary><strong>Hint 3</strong></summary>

In a bitonic sequence, one half of the search space can always be discarded.

</details>
