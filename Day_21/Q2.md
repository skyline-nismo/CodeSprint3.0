## 📖 Problem Statement

Aryan was preparing for a coding competition and came across an ancient mathematical formula known as the Fibonacci Sequence.

Curious about how recursion works, he decided to write a recursive function to calculate Fibonacci numbers. However, he got confused while defining the recursive relationship and asked for your help.

Help Aryan find the **N-th Fibonacci number** using recursion.

The Fibonacci sequence is defined as:

* **F(0) = 0**
* **F(1) = 1**
* **F(N) = F(N − 1) + F(N − 2)** for **N ≥ 2**

---

## 📥 Input Format

* The first line contains a single integer **N**.

---

## 📤 Output Format

* Print the **N-th Fibonacci number**.

---

## 💡 Example

### Input

```text
7
```

### Output

```text
13
```

---

## 📌 Constraints

| Constraint | Value        |
| ---------- | ------------ |
| N          | `0 ≤ N ≤ 40` |

---

## 💭 Hints

<details>
<summary><strong>Hint 1</strong></summary>

Every Fibonacci number depends on the previous two Fibonacci numbers.

</details>

<details>
<summary><strong>Hint 2</strong></summary>

Identify the base cases before writing the recursive function.

</details>

<details>
<summary><strong>Hint 3</strong></summary>

Express the solution to **F(N)** in terms of smaller subproblems.

</details>
