## 📖 Problem Statement

Rahil is designing a treasure hunt game where a sequence of clues is connected one after another, forming a singly linked list. According to the game's rules, the middle clue reveals the location of the hidden treasure chest.

Since the trail can contain thousands of clues, Rahil wants to identify the middle clue efficiently without first counting every clue.

Help Rahil determine the value of the middle node in the linked list.

If the linked list contains two middle nodes (i.e., the number of nodes is even), return the second middle node.

---

## 📥 Input Format

* The first line contains an integer **N**, representing the number of nodes in the linked list.
* The second line contains **N** space-separated integers representing the values stored in the nodes.

---

## 📤 Output Format

* Print a single integer.
* The integer should represent the value of the middle node in the linked list.
* If there are two middle nodes, print the value of the second middle node.

---

## 💡 Example

### Input

```text
6
1 2 3 4 5 6
```

### Output

```text
4
```

---

## 📌 Constraints

| Constraint      | Value                     |
| --------------- | ------------------------- |
| Number of nodes | `1 ≤ N ≤ 10⁵`             |
| Node value      | `-10⁹ ≤ Node Value ≤ 10⁹` |

---

## 💭 Hints

<details>
<summary><strong>Hint 1</strong></summary>

Maintain two pointers starting from the head of the linked list. Move one pointer one node at a time and the other two nodes at a time.

</details>

<details>
<summary><strong>Hint 2</strong></summary>

When the faster pointer reaches the end of the linked list, observe the position of the slower pointer. It will help you determine the required answer.

</details>
