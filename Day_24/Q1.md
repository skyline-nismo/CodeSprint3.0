## 📖 Problem Statement

Supriyo is developing a local AI chat plugin for his note-taking application. The notes are represented as a sequence of encrypted tokens, where each token has a memory weight.

The AI model can process only a continuous sequence of tokens whose total memory weight does not exceed a limit (**W**).

Help Supriyo find the maximum number of consecutive tokens that can be processed in a single batch without exceeding the memory limit.

---

## 📥 Input Format

* The first line contains two integers **N** and **W**:

  * **N** → Total number of tokens.
  * **W** → Maximum memory weight that the AI model can process in a single batch.
* The second line contains **N** space-separated integers, where the *i*th integer represents the memory weight of the *i*th token.

---

## 📤 Output Format

* Print a single integer representing the length of the longest continuous subarray whose total memory weight does not exceed **W**.

---

## 💡 Example

### Input

```text
6 10
3 1 2 4 5 1
```

### Output

```text
4
```

---

## 📌 Constraints

| Constraint                  | Value                      |
| --------------------------- | -------------------------- |
| Number of tokens            | `1 ≤ N ≤ 10^5`             |
| Maximum memory limit        | `1 ≤ W ≤ 10^9`             |
| Memory weight of each token | `1 ≤ Token Weightᵢ ≤ 10^4` |

---

## 💭 Hints

<details>
<summary><strong>Hint 1</strong></summary>

Use two pointers (left and right) to maintain a variable-size sliding window and keep track of the current sum.

</details>

<details>
<summary><strong>Hint 2</strong></summary>

Expand the window by moving the right pointer. If the sum exceeds **W**, move the left pointer forward and subtract elements until the sum becomes valid again.

</details>

<details>
<summary><strong>Hint 3</strong></summary>

Update the maximum window length whenever the current window satisfies the condition.

</details>
